# MONOQLO チーム戦ランキング

ページ: https://monoqlo-league.github.io/event-ranking/

MONOQLO麻雀部 チーム戦(イベント戦)ランキングのページ本体(`index.html`)を置くリポジトリ。管理者だけが更新する。

- ページのいちばん上に、個人ランキング(ranking)への切り替えがある。個人ランキング側にも、このページへの切り替えがある。リンクは `../ranking/` と `../event-ranking/` の形なので、リポジトリ名を変えたら両方のページを直す。
- ページの右下に「管理者用」の欄がある。パスワードを入れて「大会CSV作成ツール」「対局スケジュール作成ツール」を押すと、そのページへ移動する。パスワードが違うときは移動しない(下の「管理者用のパスワード」)。
- 集計元のデータは、別リポジトリ **event-data** に置く。
- ページは開くたびに event-data のファイルを読み込んで集計する。
- 「チーム順位」「個人順位」「順位グラフ」「スケジュール」の4つのタブがある。通算ランキングはない。
- 「順位グラフ」は、対局記録を開催日ごとに区切り、その日までの合計PTで付けたチーム順位を折れ線で表示する。対局記録を更新すれば、グラフも自動で変わる。
  - 2次以降のリーグは、**前のリーグの最終結果を1つ目の点** にし、初日を2つ目の点にする。1つ目の点の順位は前のリーグの最終順位、PTは持ち越したPT。横軸の目盛りは「予選結果」のように出る。
  - チーム名を押して開く「順位の推移」も同じ。
  - 対局記録がまだないリーグは、これまでどおり「🀄対局準備中🀄」と出る。
- 「スケジュール」は、選んだ開催日の卓組を、卓ごとに表示する。対局前は予定の組み合わせ、対局後は結果(順位・獲得PT)が出る。
- チーム順位・個人順位のチーム名を押すと、そのチームの詳細が開く。中身は次の3つ。
  - **戦績**: チーム順位の表の、そのチームの行と同じ内容(順位・合計PT・ボーダーとの差・対局数・平均PT・平均順位・トップ率・連対率・ラス回避率・着順分布)。
  - **メンバー**: メンバーごとの個人成績。
  - **順位の推移**: 順位グラフと同じ折れ線で、そのチームを強調したもの。対局記録がないリーグでは出ない。
- 個人順位のプレイヤー名を押すと、その人の成績のウィンドウが開く。
  - **戦績**: 個人順位の行と同じ内容。
  - **詳細成績**: 和了率・放銃率・副露率・立直率・立直成功率・立直放銃率・ダマ率・ダマ成功率・ツモ率・ロン率・平均立直巡目・平均和了点。それぞれの下に、もとの件数を出す。いま出るのは、第一回フォーサムリーグ(20260901)の予選だけ。ほかのリーグでは、この欄は出ない(下の「詳細成績」)。
  - チーム名を押すと、そのチームのウィンドウに切り替わる。
- 大会が2つ以上になると、見出しの下に「大会」のプルダウンが出て、大会名で切り替えられる。最初に表示されるのは、いちばん新しい大会(ファイル名の年月・枝番がいちばん大きいもの)。

## データの置き方(event-data)

名前は **開始年4桁+開始月2桁+枝番2桁** で始める。枝番は、同じ年月に大会が複数あるときの通し番号(ふつうは `01`)。

| ファイル名(2026年10月・枝番01の例) | 中身 | 作り方 |
|---|---|---|
| `20261001-master.csv` | チーム表(誰がどのチームか、リーグ構成) | 大会CSV作成ツール(event-create)で出力する |
| `20261001-games1.csv` | 1次リーグの対局記録 | 雀魂の大会管理画面から「牌譜履歴」を書き出し、名前を変える |
| `20261001-games2.csv` | 2次リーグの対局記録 | 同上 |
| `20261001-games3.csv` | 3次リーグの対局記録 | 同上 |
| `20261001-schedule.csv` | 対局スケジュール(無くてもよい) | 対局スケジュール作成ツール(event-schedule)で出力する |

- 1次リーグだけの大会でも、対局記録の名前は `-games1.csv` にする。
- **大会の開始時**: チーム表だけを置く。ページにはチームとメンバーが表示され、順位はまだ付かない。
- **大会中**: 対局記録を、その時点までの全対局が入ったCSVで上書きする。何度更新してもよい。
- チーム表に載っていないプレイヤーは、個人順位にだけ含め、チーム順位には含めない。
- チーム表が無い大会は、個人順位だけを表示する。
- 「非表示状態」が yes の対局は集計に含めない。
- チーム名とプレイヤー名は、省略せずにそのまま表示する。長い名前は、表を横に広げるか、スケジュールの卓の中で折り返す。順位グラフは、いちばん長いチーム名に合わせて右の余白を広げる。
- 牌譜履歴の書き出しによっては、プレイヤー名の末尾に中身のない括弧「()」が付く(`[JP][100000001]プレイヤー1()`)。表示のときに、この「()」を取り除く。CSVは書き換えない。中身のある括弧(`名前(仮)`)は、そのまま表示する。
- ページの見出しには、チーム表の「大会名」を使う。その下の行に、表示しているリーグの名前を `-予選-` のように出す。
- 終わったリーグを表示しているときは、見出しに「終了」の印(`終了.png`)を重ねる。最後のリーグ(ファイナル)が終わったときは「完了」の印(`完了.png`)を使う。終わったかどうかは「リーグが終わったとみなす条件」で判断する。スケジュールがない大会には、印は出ない。

## リーグが複数ある大会(予選・セミファイナル・ファイナルなど)

リーグの数、名前、進めるチーム数、PTの持ち越しは、チーム表作成ページで決める。チーム表の「リーグ構成」列に入る。

- 「チーム順位・個人順位・順位グラフ」のタブの上に、リーグ名のタブが出て、切り替えられる。最初に表示されるのは、対局記録がある最新のリーグ。
- **進出チーム**: 前のリーグの合計PTの上位チームが、自動で次のリーグに進む。
- **通過ライン**: 次のリーグがあるとき、チーム順位の表と順位グラフに通過ラインを表示する。
- **PTの差**: チーム順位の表の、合計PTの右の列に表示する。
  - 最後のリーグ以外は「ボーダーとの差」。ボーダーは、通過できるいちばん下の順位のチーム(4チーム通過なら4位)。どのチームも、そのチームとの差を表示する。ボーダーのチーム自身は「—」。
  - 最後のリーグは「トップとの差」。1位は「—」。リーグが1つだけの大会も同じ。
  - 順位が付いていないとき(1次リーグの対局前など)は「—」。
- **PTの持ち越し**: 次のリーグは、前のリーグの合計PTに持ち越しの割合(なし・半分・全部)を掛けたPTから始まる。
  半分にして小数第2位が出たときは、切り上げる(+100.1 の半分は +50.1、−100.1 の半分は −50.0)。
- チーム順位・個人順位・順位グラフは、選んだリーグの対局だけで集計する。個人のPTは持ち越さない。
- 次のリーグに進むチームは、前のリーグが終わったときに決まる(下の「リーグが終わったとみなす条件」)。
  - 前のリーグが終わるまでは、次のリーグのチーム順位には「🀄予選実施中🀄」のように出て、チームは表示しない。
  - 前のリーグが終わると、上位チームが次のリーグのチームとして表示される。次のリーグの対局記録がまだなくても、持ち越したPTの順で順位を付け、通過ラインも表示する(表のいちばん上には「🀄対局準備中🀄」と出る)。

### リーグが終わったとみなす条件

ページ全体で、次の1つの条件で判断する。

- **そのリーグの対局記録の数が、スケジュール(`-schedule.csv`)にあるそのリーグの対局の数に届いたとき。**
  例: 予選が24回戦・1回戦3卓なら72局。対局記録が72局になったら、予選は終わったとみなす。

例外は2つ。

- スケジュールを置いていない大会と、スケジュールのCSVに入っていないリーグ(日程が未定のリーグ)は、終わったか判断できない。この場合は、各所の表示を次のようにする: 前のリーグが始まっていれば、今の上位チームを、進出するチームとして仮に表示する。前のリーグが始まっていなければ、進むチームは決まっていないと表示する。
- 前のリーグの対局記録が足りないのに、次のリーグの対局記録がある場合は、前のリーグの順位で進んだものとして、次のリーグを集計する(集計できなくなるのを避けるため)。

### スケジュール

- 「スケジュール」タブを押すと、その下に開催日のタブが並ぶ。日付を選ぶと、その日の卓組が表示される。
- 最初に選ばれる日付は、今日(開催日のとき)。今日が開催日でなければ、今日より後で最初の開催日。全日程が終わっていれば最終日。
- 今日、または今日より後で最初の開催日のタブに、「本日」「次回」の印が付く。
- 回戦ごとに、卓を横に並べる。卓の中は縦に4チーム。卓の名前は `-schedule.csv` のものに「卓」を付けて出す(「薔薇」→「薔薇卓」)。もともと「卓」で終わる名前はそのまま出す。古い形式のCSV(「A卓 東」)も読める。
- 卓の並び順は、CSVの「卓」の列の順(`薔薇/金木犀/向日葵` なら、薔薇卓・金木犀卓・向日葵卓)。対局スケジュール作成ツールで入力した順と同じ。「卓」の列がない古い形式のCSVは、名前の順(A卓・B卓・C卓)。
  - **対局前**: 列は「席」「チーム」「点棒」「獲得PT」。`-schedule.csv` の組み合わせを、東南西北の順に並べる。チーム名だけを出し、点棒と獲得PTは「—」。
  - **対局後**: 列は「順位」「プレイヤー」「点棒」「獲得PT」。対局記録の結果を、1位を上にして着順に並べる。打ったプレイヤーの名前の下に、チーム名を小さく出す。点棒は終了時の点数(牌譜履歴の「N位PT」の列)。席は出さない(対局記録に席の情報がないため)。
- チーム名を押すと、そのチームの行が強調される。
- **スケジュール(`-schedule.csv`)がない大会、スケジュールのCSVに入っていないリーグ**: 対局前の卓は出せないので、終わった対局の結果だけを表示する(見出しは「対局結果」)。対局が1つも終わっていなければ、卓は何も出さず「🀄対局準備中🀄」とだけ出る。

#### スケジュールと対局記録が違うとき

対局記録を優先する。

- 対局記録を開始時刻の順に並べ、回戦に分ける。次のどれかで新しい回戦にする: 1回戦の卓の数がそろった、日付が変わった、同じチームがもう一度出た。
- 対局記録の1番目の回戦がスケジュールの第1戦、2番目が第2戦…にあたる。その回戦は、組み合わせも日付も対局記録のものを表示する。
- 卓の名前は、スケジュールのCSVの名前を使う。チームがいちばん多く重なる予定の卓の名前を当てる。予定にない対局や、スケジュールを出さないあいだの対局には、CSVの「卓」の列の名前を前から順に当てる。スケジュールのCSVがない大会と、名前が足りないときだけ「A卓」「B卓」…とする。
- 回戦の途中まで対局記録があるときは、残りの卓を予定(対局前)として表示する。

#### 2次以降のリーグ

- 2次以降のリーグのスケジュールは、**前のリーグが終わったと判断されるまで表示しない**。それまでは、スケジュールがない大会と同じ表示になる(対局前の卓は出さず、「🀄対局準備中🀄」)。
- 前のリーグが終わると、スケジュールが表示される。スケジュールは「予選1位」のような順位の枠で作られているので、枠に実際のチーム名を入れて出す。
- 前のリーグの対局記録が足りないのに、このリーグの対局記録がある場合は、終わった対局の結果だけを表示する。

#### スケジュールのCSVに入っていないリーグ(日程が未定のリーグ)

対局スケジュール作成ツールで「未定」にしたリーグは、スケジュールのCSVに行がない。そのリーグだけ、スケジュールのCSVがない大会と同じ扱いになる。

- スケジュールのタブには、終わった対局の結果だけが出る(見出しは「対局結果」。卓の名前は「A卓」「B卓」…)。対局が1つも終わっていなければ「🀄対局準備中🀄」。
- そのリーグが終わったかどうかは判断できない。見出しの「終了」「完了」の印は出ない。
- 次のリーグに進むチームは、そのリーグの対局が始まっていれば、今の上位チームを仮に表示する。
- そのリーグに進むチームは、前のリーグにスケジュールがあれば、前のリーグが終わった時点で決まる(ここは変わらない)。
- 日程が決まったら、スケジュールのCSVを対局スケジュール作成ツールに読み込み直し、そのリーグを足して出力し直す。置き換えた時点から、ふつうのリーグと同じ表示になる。
- 前のリーグが未定で、このリーグにだけスケジュールがある場合は、このリーグの対局記録が入ってから、スケジュールを表示する。
- リーグは名前で結び付ける。スケジュールのCSVのリーグ名が、大会マスターのどのリーグ名とも合わないときだけ、並び順で結び付ける。

### 詳細成績

和了率や副露率は、牌譜履歴のCSVからは出せない。いま表示しているのは、手動で集計した結果を `index.html` に直接書き込んだもの。

- 入っているのは、第一回フォーサムリーグ(20260901)の予選・48人分だけ。`index.html` の `FIXED_STATS` にある。
- データ用リポジトリからは読まない。対局記録を更新しても変わらない。
- 書き込んであるのは件数(局数・和了数・放銃数・副露数・立直数・立直成功数・立直放銃数・ツモ数・ロン数・ダマ数・ダマ成功数・立直巡目数・和了点数)。率は、表示のときに件数から計算する。
- 副露数は、副露した局の数(1局に何回鳴いても1。暗槓は含めない)。
- 対局数・着順・PTは、対局記録から出す。
- チームのウィンドウにも、戦績とメンバーのあいだに、同じ形で詳細成績を出す。チームの値は、メンバーの件数を足して計算する(メンバー4人の和了数の合計 ÷ 局数の合計、など)。集計のないリーグでは、欄ごと出さない。
- **項目のランキング**: 詳細成績の項目(和了率など)を押すと、その項目のランキングが下に出る。個人のウィンドウでは、そのリーグで集計のある全員。チームのウィンドウでは、全チーム。
  - 並びは高い順。放銃率・立直放銃率は低い順、平均立直巡目は早い順。
  - 同じ値は同じ順位。割る数が0で値の出ない人は、順位を付けずに最後に並べる。
  - ウィンドウに出している人(チーム)の行に色を付ける。名前を押すと、その人(チーム)に切り替わり、ランキングは開いたまま。
  - 同じ項目をもう一度押すか、「閉じる」を押すと、ランキングを閉じる。
- **この仕組みは仮のもの。** 牌譜から集計する方法に変えるときに、作り直す。

### 対局記録の分け方

- 雀魂でリーグごとに別の大会を立てる場合: それぞれの牌譜履歴を、`-games1.csv`、`-games2.csv` … として置く。
- 雀魂で1つの大会を続けて使う場合: あとのリーグの牌譜履歴には、前のリーグの対局も入っている。そのまま `-games2.csv` として置いてよい。前のリーグのファイルにある対局は、自動で除かれる。
- **前のリーグが終わったら、そのリーグのファイルはもう更新しない。** 次のリーグが始まってから前のリーグのファイルを上書きすると、次のリーグの対局が前のリーグに数えられてしまう。

## 設定を変えるとき

データ用リポジトリの名前を変えた場合は、`index.html` の次の行を書き換える。

```js
const DATA_REPO="event-data";
const DATA_DIR="";
```

## 管理者用のパスワード

- `index.html` には、パスワードそのものではなく、`monoqlo-tools:` のあとにパスワードを続けた文字列の SHA-256 を置いている(`const TOOL_HASH="…"`)。
- パスワードを変えるときは、ブラウザでこのページを開き、F12 のコンソールで `await toolHash("新しいパスワード")` を実行する。出てきた64文字で `TOOL_HASH` の値を置き換える。
- **これは簡単な仕切りで、本当の鍵ではない。** ページの中だけで調べているので、移動先のURLを直接開けば、パスワードなしで入れる。短いパスワードは、総当たりで割り出せる。ツールはCSVを作るだけで、リポジトリのデータは書き換えない。

## ファイル

- `index.html` … ランキングのページ本体
- `終了.png` … 終わったリーグの見出しに重ねる印
- `完了.png` … 最後のリーグが終わったときに、見出しに重ねる印

印の画像を差し替えるときは、同じ名前で上書きする。背景が透明なPNGにする。
